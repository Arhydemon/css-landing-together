CSS Свойства

display

Определяет тип отображение элеемента и его поведение в потоке документа.

Пример:
display: flex;

position

Определяет способ позиционирования элемента: static, relative, absolute, fixed или sticky.

Пример:
position: absolute; top: 0;

flex

Сокращённая запись свойств flex-grow, flex-shrink и flex-basis для flex-элементов.

Пример:
flex: 1 1 200px;

grid

Используется для создания сеточных макетов с помощью строк и колонок.

Пример:
rid-template-columns: repeat(3, 1fr);

box-model

Блочная модель включает content, padding, border и margin. Определяет итоговый размер элемента.

Пример:
box-sizing: border-box;
